## Changes that can alter verdicts / 판정에 영향을 줄 수 있는 변경 (draft)

- [REQ-RCP-002] [REQ-RCP-005] An enabled ROI is never left unjudged in silence. A board judged with an enabled ROI that is not wholly on the image, one reaching past its edge or of no size, now gets no verdict (AOI-INSP-021, naming the ROI, its box and the image's size), where before the part on the image was judged and an ROI with none on it was skipped, so the board could be OK with the place the recipe names never looked at; a scale or Golden board set after the ROIs were drawn can move an ROI held in mm there. Save Recipe refuses such an ROI (AOI-RCP-014), and Calibrate Scale… refuses a scale that would put one there (AOI-RCP-015), so a recalibration no longer stops the line at the next board; after a camera change, set the new Golden board and then calibrate the scale on it, as before. With the AI check off, which judges ROIs, the AOI checks tab no longer marks Missing Component, Polarity Error or Solder Bridge covered by an ROI, so saving asks for a reason, and each board's result notes that no ROI was judged. A recipe whose enabled ROIs are all on the Golden board judges as before; the synthetic regression set holds no ROI and is unchanged (customer notice in the pull request). / [REQ-RCP-002] [REQ-RCP-005] 활성화된 ROI가 아무 표시 없이 판정에서 빠지는 일이 없습니다. 이미지 가장자리를 벗어나거나 크기가 0인 등 이미지 안에 완전히 들어 있지 않은 활성 ROI가 있는 레시피로 판정하면, 이제 그 보드에는 판정이 내려지지 않으며 AOI-INSP-021이 그 ROI와 영역, 이미지 크기를 알려 줍니다. 이전에는 이미지 안에 있는 부분만 판정하고 이미지 안에 전혀 없는 ROI는 건너뛰었기 때문에, 레시피가 지정한 위치를 전혀 보지 않고도 보드가 OK가 될 수 있었습니다. ROI를 그린 뒤 스케일이나 골든 보드를 다시 설정하면 mm로 저장된 ROI가 그렇게 밀려날 수 있습니다.
