## Security / 보안 (draft)

- [#17] Installing the app checks the sha256 hash of every package file against the lock files, so pip refuses a file that differs from the one locked; PyTorch's CPU and CUDA builds have lock files of their own. / 앱을 설치할 때 모든 패키지 파일의 sha256 해시를 잠금 파일과 대조하므로, 잠금 시점과 다른 파일은 pip가 설치를 거부합니다. PyTorch의 CPU 빌드와 CUDA 빌드는 각각 별도의 잠금 파일을 사용합니다.
- [#17] The PySide6-Addons package is no longer installed: it holds Qt modules the app never uses, among them Qt Charts, Qt Graphs and Qt Data Visualization, which Qt offers under the GPL only. The app installs PySide6-Essentials, which holds every Qt module it uses. The CI license check now lists every shipped package with its license and whether it is allowed, and fails when a shipped package is not installed where it checks. / PySide6-Addons 패키지는 더 이상 설치되지 않습니다. 이 패키지에는 앱이 사용하지 않는 Qt 모듈이 들어 있으며, 그중 Qt Charts, Qt Graphs, Qt Data Visualization은 Qt가 GPL로만 제공합니다. 앱은 사용하는 모든 Qt 모듈이 들어 있는 PySide6-Essentials를 설치합니다. CI 라이선스 검사는 이제 배포되는 모든 패키지를 라이선스 및 허용 여부와 함께 나열하며, 배포되는 패키지가 검사 환경에 설치되어 있지 않으면 실패합니다.
