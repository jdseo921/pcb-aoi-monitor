## 기본 원칙

- 릴리스 빌드로만 데모합니다: 태그된 커밋에서 만든 서명된 설치 파일이며, 개발 환경은 쓰지 않습니다. 이 빌드는 아직
  없습니다 (코드 서명 인증서, 계획 항목 J6). 지금의 서명되지 않은 설치 파일은 우리 PC에서 리허설할 때만 씁니다
  ([install.md](../../install/install.md)).
- NG 보드로 시작해 **Compare**를 엽니다. Settings는 요청받을 때만 보여 줍니다.
- 완성된 기능만 보여 줍니다. 그래서 발표자 테마에서는 3D Profile과 **Settings**의 Stage 2~4 하드웨어 표가
  숨겨집니다. Settings는 **Reset Demo**를 위해 Admin 역할에게만 사이드바에 남습니다.
- 현장 학습은 최대 2분입니다. AI 모델 v1.0이 이미 학습되어 있어 학습을 기다릴 일은 없습니다.
- 고객 이미지가 있으면 항상 그것을 씁니다. 데모 보드 10장은 우리 도구로 그린 것이라 앱이 어떻게 동작하는지만 보여 주고,
  불량을 얼마나 잘 찾는지는 보여 주지 않습니다. 이 보드의 숫자를 정확도로 말하지 않으며, "99.9 %" 같은 말도 하지
  않습니다. 모든 주장에는 건수를 붙입니다 (고객 보드 기준으로 "NG 샘플 14장 중 14장 검출, OK 샘플 60장 중 1장을 NG로
  판정").
- 모든 데모는 고객이 가져가는 보고서로 끝냅니다: 결과 CSV와 불량 박스가 그려진 사진을 USB 메모리에 담아 줍니다.

## 데모 전마다

데모 노트북에서 전날이나 현장에서 한 번 리허설하고 줄마다 확인합니다.

- [ ] 릴리스 빌드가 설치되어 있습니다. 버전을 적어 둡니다: 제목 표시줄과 **Settings** 아래 줄에 나옵니다.
- [ ] 데모 작업 공간을 초기화했습니다: 시작 메뉴에서 `AOI PoC Inspector (Demo)`를 실행합니다(`admin`으로
      로그인되며, 정상 종료 후에는 **Home**에서 열립니다). **Settings**에서 **Reset Demo**를 누른 뒤 확인합니다.
      발표자 테마가 켜져 있었다면 그대로 켜져 있습니다. **Home**에서 **Presenter theme**를 켠 상태로 둡니다.
- [ ] Wi-Fi가 꺼져 있습니다. 앱은 네트워크가 필요 없습니다 ([ports.md](../../install/ports.md)).
- [ ] 프로젝터를 1920 × 1080과 1366 × 768에서 확인했습니다: 스크립트의 모든 페이지가 뒷줄에서 읽힙니다.
      스크립트가 여는 모든 페이지와 탭이 1366 × 768에 맞으며, 판정, 결함 상자, **Compare**의 표가 스크롤 없이
      보입니다. 앱의 높이가 900 px 미만이거나 너비가 1400 px 미만이면 발표자 테마의 글자가 18 pt가 아니라
      16 pt입니다 ([화면 크기](../../tests/2026-10-screen-sizes.md)). 1366 × 768 화면에서 최대화하면 Windows가 제목
      표시줄과 작업 표시줄을 남기므로 앱은 약 1366 × 697(Windows 11에서는 689)로 더 작습니다: 이때 **Inspection**의 **Start**와
      **Compare** 표의 마지막 두 줄(데모 보드의 AI score 포함)이 화면 아래 끝 바로 밑에 있으므로, F5로 시작하고 그
      줄들은 아래로 스크롤해서 봅니다.
      1366 × 768보다 작은 화면만 받는 프로젝터라면 녹화본을 틉니다.
- [ ] **Presenter theme**가 켜져 있습니다 (**Settings**에서 **Presenter theme**).
- [ ] Windows 알림이 꺼져 있고 (집중 모드 또는 방해 금지), 다른 앱은 열려 있지 않습니다.
- [ ] 노트북에는 이 고객의 데이터만 있습니다: 다른 고객의 이미지, 보고서, 이름이 앱, 바탕 화면, 최근 파일 어디에도
      없습니다.
- [ ] 5분 스크립트 녹화본이 노트북과 USB 메모리에 있습니다.
- [ ] 고객 보고서용 빈 USB 메모리에 고객 이름을 붙였습니다.
- [ ] 5분 스크립트를 처음부터 끝까지 한 번 돌리고 다시 **Reset Demo**를 했습니다.

## 문제가 생기면

| 상황 | 할 일 |
|---|---|
| 앱이 저절로 닫힘 | 시작 메뉴에서 `AOI PoC Inspector (Demo)`를 실행합니다. 30초 안에 데모 작업 공간이 `admin`으로 로그인된 채 원래 테마로, 마지막에 보던 페이지에서 다시 열립니다(직접 닫은 경우에는 **Home**에서 열립니다). "다시 열겠습니다"라고 말하고 마지막 단계부터 이어 갑니다. 운영자 화면을 보여 주던 중이었다면 먼저 **Switch User**로 `operator`로 다시 로그인합니다 |
| 학습이 느림 | 남은 시간이 2분을 넘으면 **Cancel**을 누르고 이미 학습된 AI 모델 v1.0을 씁니다: "같은 보드로 미리 학습한 것입니다". 잃는 것은 없습니다 |
| 판정이 이상해 보임 | **Compare**를 엽니다. 표에 검사마다 값과 임계값이 있고, 그 아래 상자가 이유를 쉬운 말로 설명합니다. 그것으로 설명하고 추측하지 않습니다 |
| 메시지가 나옴 | 소리 내어 읽습니다. 무슨 일이 있었고 무엇을 할지 코드와 함께 적혀 있습니다. 그대로 하고 이어 갑니다. Show Details 버튼에는 지원팀을 위한 기술적인 내용이 있으니 고객 앞에서는 열지 않습니다 |
| 데모가 틀어짐: 잘못 누름, 보드를 두 번 돌림 | 발표자 테마를 끄지 않고 어느 페이지에서든 세 번의 클릭으로 깨끗한 데모로 다시 시작합니다: 사이드바의 **Settings**, **Reset Demo**, 그리고 Yes. 데모가 설치 당시 상태로 **Home**에서 다시 열립니다. 실행 중인 작업이 멈춘 뒤 10초 안에 끝납니다(AI 모델 테스트는 폴더를 마친 뒤 멈춥니다). **Inspection**을 누르고 **Start**를 눌러 보드를 다시 돌립니다. `operator`로 로그인되어 있다면 Settings는 Admin의 페이지이므로 먼저 **Switch User**로 `admin`으로 로그인합니다 |
| 발표자 테마가 방해되거나 테마가 숨기는 페이지가 필요함 | `admin`으로 로그인한 상태에서 어느 페이지에서든 헤더의 **Exit presenter theme**를 누릅니다: 한 번의 클릭입니다. 다시 켤 때는 **Settings**의 **Presenter theme**를 씁니다 |
| 앱이 열려 있는데 다시 실행함 | 이미 열려 있는 앱이 그대로 앞으로 나옵니다. 잃는 것도 다시 시작되는 것도 없습니다. 대신 앱이 이미 열려 있다는 메시지가 나오면 OK를 누르고 작업 표시줄에서 그 창으로 전환합니다 |
| 프로젝터 없음 | 녹화본을 틀고 보고서는 평소처럼 건넵니다 |

## 데모 후

1. 보고서가 담긴 USB 메모리를 건넵니다 (5분 스크립트의 마지막 단계).
2. **Settings**에서 **Reset Demo**를 눌러 다음 데모를 깨끗하게 시작합니다. 발표자 테마는 그대로입니다.
3. 고객이 서면으로 보관에 동의하지 않았다면 노트북에서 고객 이미지를 지우고, 무엇을 얼마 동안 보관하는지 적어 둡니다.
4. 고객의 질문과 다음에 보고 싶어 한 것을 적습니다. Stage 1 시험 계획에 들어갑니다.

## 스크립트를 믿을 수 있는 이유

`tests/test_demo_scripts.py`가 모든 풀 리퀘스트에서 발표자 테마로 5분 스크립트와 15분 스크립트를 실제로 클릭해 보고,
도중에 메시지가 하나라도 나오거나 페이지가 1920 px 화면보다 넓으면 빨간색이 됩니다. 45분 스크립트는 클릭해 보지
않습니다. 이 테스트는 이 파일들의 굵은 이름이 실제 버튼이나 페이지인지, 문장이 Charter의 용어를 쓰는지, 각 파일에
한국어 초안이 있는지도 확인합니다. `tests/test_demo_fit.py`는 스크립트가 보여 주는 모든 페이지와 탭을 발표자 테마와
어두운 테마의 1366 × 768에서 열어 보고, 페이지나 입력란 패널이 옆으로 스크롤되거나, 글이 잘리거나, 판정, 결함 상자,
**Compare** 표의 줄이 보이지 않으면 빨간색이 됩니다. Customers & Launch는 이와 별도로 각 독자 역할의 사람이
릴리스 빌드에서 스크립트를 따라 해 보도록 요구합니다. 릴리스 빌드가 아직 없어서 이것은 아직 하지 못했습니다.
